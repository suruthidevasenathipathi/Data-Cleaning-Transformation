# Data-Cleaning-Transformation

I have cleaned the raw data by using formulaes and used functions, Conditional formatting to get the data accuracy. And as well highlighted data in Category column and used Color Scales in Price column. Finally a messy data turned to a cleaned data as expected

## Description
Received a messy data with 
Missing Values
Inconsistence data 
Duplicates

Work done:
Initially, i cleaned and trimmed the date by using formulae =trim(clean(data) and cleaned the data from unnecessry spaces, non printable characters.
Then, to fill the missing values used formulae as If(is blank(data) formulae and given as NA
For Inconsistence data like no proper format in data set used Proper function with formulae as =proper() nad arranged the data
Since this is the Product id no duplicates found for entire row
Used conditional formatting to highlight data in Category column and then used Color Scales in Price Column 
As instructed created a new column to Merge data from brand and product column to create a Product Brand column
To Create a new column as Manufacturing date as instructed used left function with formulae as =left(text)
To create a new column as Product Brand column created a dupe column and used Concatenate formulae as =concatenate(text," ",text) and got the expected result
